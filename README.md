# 🏛️ Greek Ledger

**Greek Ledger** is a full-stack web app designed to simplify chapter financial operations for the brothers of **Lambda Phi Epsilon (Nu Chapter) at SUNY Buffalo**.

With our experience, reimbursement requests and receipt photos frequently get lost in long group chats. Greek Ledger replaces those scattered messages with a centralized, online system for submitting, reviewing, and tracking expenses in real time.

### Key Features
* **Role-Based Access:** Different views and permissions for active members and the chapter treasurer.
* **Easy Expense Submissions:** Members can quickly fill out an expense form and attach receipt photos uploaded directly to Cloudinary.
* **Treasurer Approval Queue:** A clean dashboard for treasurers to review, approve, or reject pending reimbursements.
* **Automatic Budget Tracking:** Deducts approved expenses directly from chapter budget categories (Social, Philanthropy, Operations, etc.).
* **CSV Export:** Download expense history into spreadsheet files for chapter meetings and financial check-ins.

### Tech Stack
* **Frontend:** React, Tailwind CSS
* **Backend:** Node.js, Express.js, JWT
* **Database:** MongoDB Atlas (Mongoose)
* **Image Storage:** Cloudinary API
